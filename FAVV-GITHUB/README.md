# FAVV Assistent

Dit is de veilige, eenvoudige startversie.

## Meteen gebruiken
Dubbelklik op `03_OPEN_APP.bat` of open `index.html`.

## Veiligheid
- `index.html` is de werkende app.
- `WERKENDE_APP_RESERVEKOPIE.html` is een onaangeroerde reservekopie.
- `SUPABASE_DATABASE.sql` is alleen voor een nieuw Supabase-testproject.
- Zet nooit geheime sleutels in GitHub of in `index.html`.

## Belangrijk
De app blijft voorlopig lokaal werken. Supabase wordt pas later gecontroleerd gekoppeld. Daardoor verlies je de huidige werking niet.
